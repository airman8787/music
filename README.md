# 四音フレーザー

歌詞を入れてジャンルとスケールを選び、主旋律の核になる **4音のモチーフをパッドで叩く** と、コード進行とメロディを自動で作るフレージングアプリです。

## 使い方

GitHub Pages を有効にすると <https://airman8787.github.io/music/> で開けます（スマホでは「ホーム画面に追加」でアプリのように使えます）。手元では `index.html` をブラウザで開くだけで動きます（ビルド・サーバー・外部ライブラリなし）。

1. **歌詞** — 1行＝1フレーズ。`[Verse]` `[Pre]` `[Chorus]` `[Bridge]`（Aメロ／Bメロ／サビ／Cメロも可）で区切る。タグがなければ空行ごとに自動で割り当て。空欄でもメロディだけ作れます。
2. **ジャンル（複数可）** — 選んだ順に役割が付きます。**主語**＝形式とコード進行、**動力**＝ドラムとベース、**色**＝音色。
3. **スケールとキー・拍子** — 選んだジャンルで使えるスケールが、共通度の高い順に並びます。拍子は 4/4・3/4・6/8・5/4（3+2）・7/8（2+2+3）・7/4（4+3）。BPMは常に四分音符基準です。
4. **四音モチーフ** — パッドを4回叩く。リズム型は拍子ごとに5種類。感情別の作例からも選べます。
5. 画面下のバーで **再生／ループ／BPM／別案**。小節をタップするとそこから再生します。

書き出し：MIDI（メロディ・コード・ベース・ドラム、歌詞付き）、譜面テキスト、Suno用の Style／Lyrics テキスト（字数カウンタ付き）。

## 生成の考え方

- サビ1行目の頭はモチーフそのもの。コード進行は、ジャンルの定番とスケール固有の進行から、モチーフに最も合うものを選びます。
- Verse はモチーフの断片を低い音域で、Pre-Chorus は1小節ごとに1段ずつ上げ、Bridge は反行・逆行で展開します。
- 歌詞の音数（かな＝1音、漢字＝概算2音、英語＝音節）に合わせてモチーフのリズムを分割／結合します。ずれる行は「音数チェック」で補正できます。
- 強拍と長い音はコードとぶつからない音へ、句末はコードトーンへ、サビの最後は主音へ寄せます。

4/4以外の拍子ではドラムとベースが拍子専用の型になり、ジャンルは音色とコード進行に効きます。曲の途中で拍子を変えることはできません。

BPM・進行・グルーヴは制作の出発点で、ジャンルの規格ではありません。陽音階・陰音階などは平均律での近似です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `js/data.js` | スケール15種・ジャンル35種・グルーヴ・拍子6種・モチーフ作例24種 |
| `js/theory.js` | 音名、スケール、ローマ数字コードの解釈 |
| `js/lyrics.js` | 歌詞のセクション分けと音数の概算 |
| `js/generator.js` | コード進行の選択とメロディ生成 |
| `js/arrange.js` | 伴奏（和音・ベース・ドラム）のイベント化 |
| `js/export.js` | MIDI／譜面テキスト／Suno用テキスト |
| `js/audio.js` | Web Audio の内蔵シンセと再生 |
| `js/app.js` | 画面 |

テスト：`node tests/run.js`
